# Tuition Management System

A Database Systems course project at Punjab University College of Information Technology (PUCIT).

The system models the operations of a tuition center, covering:
- Centers, tutors, courses and batches (with schedules)
- Students, guardians and course enrollments
- Fee structures, payments, discounts, payment history and fee reminders
- Attendance, course materials and student performance tracking

## Contents
- ERD of the system
- Relational schema and relational model
- Description of the relations
- SQL scripts for table creation and data insertion
- Views and SELECT queries for common reports
